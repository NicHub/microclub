<p>J’ai développé un logiciel avec l’environnement Arduino.</p>
<p>Je désire mettre ce logiciel dans un hardware personnalisé donc pas sur une carte Arduino.</p>
<p>Comment trouver l’emplacement où se trouve le fichier hex compilé ?</p>
<p>Voici la marche à suivre :</p>
<p>1 Ouvrir l’environnement Arduino, sous l’onglet « fichier » sélectionner l’option « Préférences » :</p>
<p><a href="/media/2015/05/Préférences.png"><img alt="Préférences" height="300" src="/media/2015/05/Préférences-257x300.png" width="257"/></a></p>
<p>2 Cocher l’option « compilation » :</p>
<p><a href="/media/2015/05/Coche.png"><img alt="Coche" height="162" src="/media/2015/05/Coche-300x162.png" width="300"/></a></p>
<p> </p>
<p>3 Compiler le logiciel. Dans la fenêtre de sortie, repérer le répertoire du fichier hex :</p>
<p><a href="/media/2015/05/OUT.png"><img alt="OUT" height="97" src="/media/2015/05/OUT-300x97.png" width="300"/></a></p>
<p>Ensuite, vous pouvez utiliser votre programmateur et transférer le logiciel dans votre carte personnalisée !</p>
