<p>Parfois il peut être très pratique de connecter son smartphone Android à windows et l’utiliser dans une fenêtre comme une autre applications windows. C’est aussi une solution pour enregistrer un tutoriel ou présenter une application sur un projecteur.</p>
<figure><img alt="" height="373" src="/media/2023/04/word-image-5136-1.png" width="625"/></figure>
<p>Voici les étapes à effectuer pour réaliser cette connexion :</p>
<p>1 sur le smartphone, depuis le « play store » d’applications, recherchez « lien avec windows » et installer l’application.</p>
<figure><img alt="" height="105" src="/media/2023/04/word-image-5136-2.png" width="74"/></figure>
<p>2 Double cliquez sur le bouton Lien avec Windows et activez la connexion :</p>
<figure><img alt="" height="248" src="/media/2023/04/word-image-5136-3.png" width="209"/></figure>
<p>2 Sur votre PC, allez dans les paramètres, puis sous bluetooth et appareils, choisissez « Mobile connectés » et appuyez sur le bouton « ouvrir Mobile Connectés »</p>
<figure><img alt="" height="377" src="/media/2023/04/word-image-5136-4.png" width="531"/></figure>
<p>La fenêtre principale va s’ouvrir :</p>
<figure><img alt="" height="267" src="/media/2023/04/word-image-5136-5.png" width="639"/></figure>
<p>Zone 1 : vous avez les informations système du smartphone, en double cliquant sur le symbole rectangulaire, votre téléphone apparaitra dans une fenêtre.</p>
<p>Zone 2 : vous pouvez voir les derniers messages reçus.</p>
<p>Zone 3 : vous pouvez visualiser toutes les photos du téléphone</p>
<p>Zone 4 : vous pouvez voir toutes les applications contenues dans le smartphone. En double cliquant dessus, vous pouvez les lancer.</p>
<p></p>
<p>Remarque : Il semblerait que les smartphone de marque Samsung ont un peu peu plus d’options disponibles que les autres marques de smartphone.</p>
