Suite à la conférence donnée au microclub le 22.02.2013, vous pouvez trouver toute la documentation ainsi que les exemples de programmes sur le site [FraniDuino](http://franiduino.franic.eu "FraniDuino").

Vous y trouverez une documentation simplifiée du langage C pour Arduino, une théorie sur les diagrammes états/événements.

Il y a aussi le code source de tous les projets de feux de trafic ! ainsi que des diagrammes états/événements.

Bonne programmation sur Arduino et compatibles !
