Le flux RSS du Microclub est disponible à cette adresse :

{{< rss-address >}}

Copiez cette adresse dans un lecteur RSS, puis choisissez **Ajouter un flux** ou **S’abonner**. Le lecteur vérifiera automatiquement les nouveaux articles.

### macOS

- [NetNewsWire](https://netnewswire.com/) — gratuit et open source ;
- [Lire](https://read.reederapp.com/) — lecteur payant.

### iOS/iPadOS

- [NetNewsWire](https://netnewswire.com/) — gratuit et open source ;
- [Lire](https://read.reederapp.com/) — lecteur payant.

### Windows

- [Thunderbird](https://www.thunderbird.net/) — ajoutez un compte **Flux** puis l’adresse du flux ;
- [QuiteRSS](https://quiterss.org/) — lecteur RSS dédié pour ordinateur.

### Linux

- [Thunderbird](https://www.thunderbird.net/) ;
- [Liferea](https://lzone.de/liferea/) — lecteur RSS léger pour le bureau ;
- [NewsFlash](https://gitlab.com/news-flash/news_flash_gtk) — lecteur moderne pour GNOME.

### Android

- [Read You](https://github.com/Ashinch/ReadYou) — lecteur libre et open source ;
- [Feeder](https://github.com/spacecowboy/Feeder) — lecteur libre et sans publicité ;
- [NewsBlur](https://www.newsblur.com/) — service synchronisé entre appareils.

Sur mobile, ouvrez l’application choisie, appuyez sur **Ajouter un flux**, collez l’adresse ci-dessus, puis validez.
