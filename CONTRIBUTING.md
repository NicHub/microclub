# Contribuer

## Article

Créez le fichier avec `hugo new articles/AAAA/MM/JJ/titre.md`, complétez les métadonnées et passez `draft` à `false`. Les noms de fichiers et médias doivent être courts, descriptifs et sans espace.

Avant de proposer le changement :

```sh
hugo --gc --minify --printPathWarnings
```

## Commentaire

Ajoutez le commentaire directement à la fin du fichier de l’article, sous `## Commentaires`, avec un titre de niveau 3 contenant le nom public et la date. Répondez avec `### ↳ Réponse — Nom — date`.

Les contributions discriminatoires, publicitaires, illégales, hors sujet ou contenant des données personnelles sont refusées. Un mainteneur valide chaque changement avant publication.
