# Microclub Modern

Thème Hugo par défaut de microclub.ch. Il contient uniquement la présentation :

- `layouts/` pour les gabarits ;
- `assets/` pour les feuilles de style et le JavaScript traité par Hugo Pipes.

Les contenus et médias restent à la racine du projet. Le thème peut donc être remplacé temporairement avec :

```sh
make serve THEME=nom-du-theme
```
